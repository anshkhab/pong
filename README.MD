## Pong

A simple Pong game inspired by a [Telestar
ad](https://www.youtube.com/watch?v=uCqIkgFKHr4). Built in C++ using
[raylib](https://www.raylib.com/). I used Emscripten to compile the game code
(C++) and the raylib graphics library into WebAssembly, allowing the game to
run directly in a web browser. Sound from
[Soundstripe](https://www.soundstripe.com/).

[Link to play Pong](https://anshkhab.github.io/pong/)
