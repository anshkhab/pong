## Pong

A simple Pong game built in C++ using [raylib](https://www.raylib.com/). I
used [Emscripten](https://emscripten.org/) to compile the game code and the
raylib graphics library into WebAssembly, allowing the game to run directly in
a web browser.

[Link to play Pong](https://anshkhab.github.io/pong/)
